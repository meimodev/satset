Guest self-order

lib/server/guest_app_html.dart · ADR-0027 / ADR-0029

A different audience gets a different skin. The guest holds their own phone, has never seen this before, will use it once, and is sitting in a warm room they chose to be in — none of which describes a waiter mid-rush. So: cream and brown, not amber on charcoal. No dark mode. No design tokens, no shared CSS, no font download, no framework — one self-contained file of inline CSS and vanilla JS, served verbatim over the cleartext guest plane so it paints instantly on venue Wi-Fi with no internet at all (ADR-0029). It shares the staff app's grammar without sharing its palette: the same required/optional labelling, the same status vocabulary, the same refusal to imply payment. That is the part worth keeping consistent.

Photos load lazily as blobs after the list paints, so a slow image never delays the menu. Items with variants show "mulai Rp …" rather than a single price — the guest must not discover a higher number at checkout. The cart bar is fixed to the viewport bottom and hidden until the cart is non-empty, so an empty menu is a clean page.

Native radio and checkbox inputs, not custom controls. A guest's phone already knows how to render these, they are accessible for free, and they cannot break on a browser nobody tested. Required groups are labelled "wajib" in warn beside the group name — same convention as the staff sheet, different word size. Client-side validation is a courtesy; the server re-validates every line regardless. Note caps at 140 chars — longer than the staff field, because a guest cannot be asked to be terse.

Guest orders land as pendingReview and never auto-fire (ADR-0028) — a waiter confirms before the kitchen sees them. The status copy says so out loud rather than showing a spinner: "Menunggu konfirmasi pramusaji…". Seven internal statuses collapse to five guest-facing words — menunggu, disiapkan, siap, disajikan, ditolak. The guest does not need the kitchen's state machine, only their own answer.

Five named failures, each with its own sentence and each ending in something the guest can actually do — call a waiter, join the right Wi-Fi, rescan. "Silakan panggil pramusaji" is the universal fallback: there is always a human in the room, which is the one advantage this surface has over any app store. An unrecognised code still renders, appending the raw code and HTTP status in small print rather than hanging on "Memuat…" forever. Silent failure on a guest's own phone is unrecoverable — nobody is watching the logs.
