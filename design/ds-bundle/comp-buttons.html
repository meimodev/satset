Buttons

No Button widget exists — these are the shapes that recur

Known debt. There is no shared button in ui/core/widgets/. Every call site builds its own ElevatedButton or GestureDetector + Container. The heights and radii below are the values that repeat often enough to be treated as the system; the variance that remains is drift, not intent.

Primary — 52px, r-xl (18)

accent fill, accentInk label. The disabled variant does NOT fade the accent — it swaps to bg3 + textLo, because a 40%-opacity amber on charcoal still reads as "tappable" from arm's length. Busy keeps the button's footprint and swaps to accentSoft + spinner, so a second tap lands on an inert button rather than a moved one. The trailing amount is mono at 70% ink: it is confirmation, not the label.

Sizes

44 is the floor for anything a walking waiter taps. 38 appears only inside sheets and admin rows, where the user is stationary and looking.

Secondary & destructive

Ghost is a border1 outline on transparent — never a filled grey, which is the legacy-POS tell. Destructive is urgentSoft on an urgent rule: red is scarce, so a red button means the action cannot be undone.

Banner buttons — SeedDataBanner

Paired filled + ghost, r-md, 11px vertical padding. The dismissive option is never a bare text link — it has the same hit area as the affirmative one.

36×36, r-md, bg2 on border0. The refresh button swaps to a spinner in place and goes inert during the fetch — it never shows a spinner elsewhere on screen while the icon stays live.

Press feedback

PressScale wraps the tappable, not the label: 0.97 in 90ms down, 220ms back. The child keeps owning the tap. Under reduced motion it is a pass-through.

On a filled accent button the label stays accentInk (#160D04) — near-black on amber, which survives daylight. Only text ON the background switches to accentText (#A34B00).

The hard shadow is a solid ink offset with zero blur — it only paints when the element owns its own fill AND has a border AND a radius AND is rectangular. A lift on a shapeless element reads as a rendering bug, so SatBox.d refuses it.
