SatSet

LAN restaurant ordering, Android-only, offline-first. One APK runs as Server or Client, paired over Wi-Fi. This system is transcribed from lib/ui/core/design/ — the Dart tokens are the source of truth; these pages mirror them.

Thesis

Sharp, warm, dependable. Amber #FF9233 on charcoal — an instrument panel that doesn't feel cold, in a business that is fundamentally about hospitality.

Who uses it

  • Waiter — phone, one-handed, walking. Half-second glances. Busiest, least forgiving context.
  • Kitchen — tablet KDS on a hot line, read at 1–2 m, often never touched.
  • Cashier — settling and splitting. Accuracy over speed.
  • Owner / admin — menu, staff, reports. Seated, not rushed.
  • Guest — own phone, web SPA, zero training, one-shot use.

Principles

  • Glanceable beats dense. When density and legibility conflict, legibility wins.
  • Color is signal, not decoration. urgent earns its red by being rare.
  • State must be unambiguous. Pair every state with text, shape, or position — never color alone.
  • Both themes, both real. Six palettes ship. Never hardcode a Color.
  • Quiet motion, honest feedback. Transform + opacity only; reduced motion yields the final state instantly.
  • Degrade loudly, fail safely. Offline and stale-cache states are first-class UI.

Not this

Legacy Windows POSGray gradients, beveled buttons, 2005 enterprise chrome. This is what's being replaced.
Stock Material 3No purple seed. useMaterial3 is a substrate, fully overridden.
Food-delivery appNo hero photography, gradients, promo banners, gamification. Staff tools, not a storefront.

Language

UI copy is Bahasa Indonesia — kosong, terisi, habis, Siap di pass. All strings route through lib/core/localization/app_strings.dart. Voice is direct and unfussy: state what happened, not how the system feels about it. No exclamation marks, no apology copy.
