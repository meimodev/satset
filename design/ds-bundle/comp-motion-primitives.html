Motion primitives

anim.dart · every one collapses to its final frame under reduced motion

The curve is a token: satEaseOut = Cubic(0.22, 1, 0.36, 1), re-exported from anim.dart so a screen animating something bespoke needs one import, not two. Transform and opacity only. Nothing animates a colour, a layout constraint or a scroll position — those cost frames on the cheap Android hardware this runs on, and a dropped frame during a send is worse than no animation at all. Callers never branch on reduced motion themselves. Each primitive checks MediaQuery.disableAnimationsOf and returns its child unchanged.

Reveal — entrance cascade

Meja 4 · kosong
Fade + 14px rise over 420ms, 55ms per sibling. The stagger is clamped at index 10 — a 40-row board would otherwise leave the last row waiting two seconds, which reads as a hang, not a reveal. Rows inside a recycling ListView pass a stable animKey (an item id). The cascade plays the first time that key is seen this session and is skipped on every later mount, so scrolling back does not re-trigger it.

AnimatedSwitcher over height + opacity, 220ms, top-aligned. Used where an editor block toggles on (tracked stock) or a dynamic row list grows and shrinks — the swap animates instead of popping. Snaps under reduced motion.

AnimatedReflow — container grows with its children

AnimatedSize, 240ms, top-centre. Wraps a list so rows added or removed beneath it slide rather than jump. Pairs with keyed children; degrades to a plain pass-through.

AnimatedBarFill — 620ms from zero

Grows from zero on first paint and eases to a new width whenever the factor changes — so a filter switch reads as the same bar moving, not as a new bar appearing.

GrowBarV — 560ms from baseline

Vertical twin of the fill, used by the cover-trend and hourly-revenue mini charts. Bars grow from the axis, never from the top — growth from the wrong edge inverts the reading of a chart for the half-second it is in flight.

PressScale — tap it

Kartu
0.97 in 90ms down, 220ms back. The child keeps owning the actual tap — this only adds the scale, so an InkWell ripple and an onTap still work underneath. Asymmetric on purpose: the dip must land within a frame or two of the finger, the release can take its time.

AnimatedCount

128 cover hari ini
500ms tween between integer values, rounded each frame. Used where a count changes after a filter or an edit — the number rolls so the eye follows it rather than re-reading a field that silently changed. Snaps instantly under reduced motion.

Two clusters and almost nothing between them: 90–280ms for anything a finger caused, 500–620ms for anything data caused. The long tail (1600ms pulse, 1900ms auto-return) is ambient or procedural, never blocking. satMotion(context, ms) returns Duration.zero under reduced motion, so an AnimatedContainer written with it collapses without a branch at the call site. No animation delays a confirmation. The Sent screen paints its tick at frame zero and animates the stations afterwards — the acknowledgement is never the thing being waited for.
